## UI display limitations (PR #3)

`monthsLabel(months)` in `client/src/components/DebtOverview.tsx` (lines 25–36):

```ts
const totalDays = Math.round(months * 30.44);
const years = Math.floor(totalDays / 365);
const restDays = totalDays % 365;
const restMonths = Math.floor(restDays / 30.44);
const days = Math.round(restDays % 30.44);
if (years > 0) parts.push(`${years} …лет`);
if (restMonths > 0) parts.push(`${restMonths} мес.`);
if (days > 0 && years === 0) parts.push(`${days} дн.`);
```

Because of `&& years === 0`, the day component is dropped for durations over
~1 year, so the fractional month is invisible for P1/P2/P4:

| Golden | Until fix (UI) | After fix (UI) | Difference visible? |
|---|---|---|---|
| P1 72.9235 | 6 лет (2 дн. скрыты) | 6 лет (30 дн. скрыты) | Нет |
| P2 15.9700 | 1 год 3 мес. (0 дн.) | 1 год 3 мес. (30 дн. скрыты) | Нет |
| P3 31.0000 | 2 года 6 мес. | 2 года 7 мес. | Да (restMonths изменился) |
| P4 9.0015 | 9 мес. (0 дн.) | 9 мес. (0 дн.) | Нет |

`baselineMonths` — целое (calendar months from `summary.debtFreeDate` via
`monthsBetween`), поэтому `savedMonths = baseline − accelerated` — дробное,
но для durations > 1 года разница в днях скрывается тем же правилом.
